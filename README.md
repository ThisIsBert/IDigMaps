# IDigMaps
Ein Tool zur Georeferenzierung und Vektorisierung von Kartenbildern, die im JPG- oder PNG-Format vorliegen. 
Das Tool erlaubt es, vorhandene pixelbasierte Karten auf der OpneStreetMap zu georeferenzieren und
in die passende Projektion zu transformieren und anschließend zu vektorisieren.
Der Export erfolgt als GeoJSON.
