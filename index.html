IDigMaps

Georeference an image with GCPs and digitize polygons.

Instructions

  1. Load a map image and zoom/pan the image picker.
  2. Press G to start a new GCP (or use the button).
  3. Click the image picker, then click the map.
  4. Add at least 3 GCPs for affine, 6+ for TPS.
  5. Compute transform, adjust overlay, and digitize polygons.
